# APML Doctrine (PROVISIONAL)

Status: draft. The Wix site could not be read from the build sandbox, so this
opinion rests only on the repository tagline, "New Engaging Software for the
Net Universe". It must be revised against the real site text and the real list
of Software Agencies before it is treated as final.

## Overall theme (opinion)

"Engaging" and "Net Universe" point to one idea: software that is meant to be
used on the open network and judged by how people respond to it. A doctrine
that fits that is:

1. **Open by default.** Every agency ships something a stranger can reach with a URL.
2. **One product per agency.** Each agency has its own name, folder, page, feed and release notes, so it can be adopted, forked or retired without touching the others.
3. **Plain technology.** HTML, CSS, JavaScript, JSP and Servlets, with no framework that hides how the page is made.
4. **Provenance stated.** Each agency page names its author, date, license and any upstream work, in the same spirit as the metadata blocks used in the SLeeLa projects.

## Each agency as a product

For every agency, the site should answer the same five questions, in this
order: what it does, who it is for, how to try it, how it is licensed, and
where its source lives. Use `source/main/webapp/agencies/_template/` as the
starting point.
